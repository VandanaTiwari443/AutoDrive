# AutoDrive — Car Showroom Platform

AutoDrive is a full-stack car showroom web application built with Next.js, React, Node.js, Express, and MongoDB. It allows users to explore cars, compare vehicle details, estimate ownership costs, and request test drives. It also includes an AI-powered assistant for car-related questions.

## Features

- **Car Listings:** Browse available cars and view detailed specifications.
- **Search and Filters:** Find cars based on relevant criteria.
- **Car Details:** View information such as price, mileage, fuel type, transmission, and seating capacity.
- **User Authentication:** Sign up and log in securely.
- **Test-Drive Requests:** Submit test-drive enquiries.
- **Ownership Cost Calculator:** Estimate vehicle running costs using mileage and distance.
- **AI Car Assistant:** Ask car-related questions and compare vehicles.
- **Responsive Design:** Interface designed for desktop, tablet, and mobile screens.
- **Admin Features:** Manage bookings and showroom information, if enabled in the deployed version.
